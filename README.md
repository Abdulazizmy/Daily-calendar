# التقويم اليومي

تقويم عربي بسيط يجمع في مكان واحد:

- التاريخ الميلادي والهجري
- مواقيت الصلاة (الرياض) مع العدّ التنازلي للصلاة القادمة
- تقويم شهري تفاعلي مع إمكانية إضافة أحداثك الخاصة (تنحفظ في المتصفح)
- مباريات الهلال القادمة مع حفظ النتائج

يشتغل كتطبيق (PWA): تقدر تثبته على شاشة الجوال ويشتغل بدون إنترنت.

## تثبيته على الجوال

- **أندرويد (Chrome):** القائمة ⋮ ثم "تثبيت التطبيق".
- **آيفون (Safari):** زر المشاركة ثم "إضافة إلى الشاشة الرئيسية".

## تحديث المباريات

كل المباريات في ملف `matches.json`. لتعديل مباراة أو إضافة جديدة افتح الملف في GitHub واضغط أيقونة القلم، وكل مباراة بهذي الصيغة:

```json
{
  "start": "2026-10-10T21:00:00+03:00",
  "home": "الهلال",
  "away": "الاتحاد",
  "competition": "الدوري السعودي",
  "homeLogo": "hilal",
  "awayLogo": "ittihad",
  "venue": "المملكة أرينا"
}
```

- `start`: تاريخ ووقت المباراة بتوقيت السعودية، بنفس الصيغة أعلاه (`+03:00` في النهاية).
- `homeLogo` و`awayLogo`: مفتاح شعار جاهز (`hilal` و`ittihad` و`sadd` و`qadsiah` و`fateh` و`hazem`) أو رابط صورة كامل، أو اتركه `""` بدون شعار.
- `venue`: الملعب، ويجوز يكون `""`.
- انتبه للفواصل `,` بين المباريات، وآخر مباراة بدون فاصلة بعدها.

## تحديث نسخة التطبيق

إذا غيّرت `index.html` أو أي ملف آخر، غيّر `VERSION` في أول ملف `sw.js` (مثلاً من `v2` إلى `v3`) عشان يتحدث عند الجميع. تعديل `matches.json` وحده يوصل تلقائياً بدون تغيير الرقم.
